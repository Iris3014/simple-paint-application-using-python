# Simple Paint Application  

A simple paint application built using Python's `tkinter` library.  
It allows you to draw freely on a canvas, choose colors, and clear the canvas with one click.

## Features
- **Drawing Tool** – Draw on the canvas with mouse drag.
- **Color Palette** – Quick color selection from preset colors.
- **Custom Colors** – Pick any color using a color chooser.
- **Clear Button** – Wipe the canvas to start fresh.
- **Resizable Canvas** – Canvas adapts to window size.

## Requirements
- Python 3.x
- tkinter (comes pre-installed with Python on most systems)

## Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/simple-paint-app.git
    cd simple-paint-app
    ```
2. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
3. Run the application:
    ```bash
    python paint_app.py
    ```

## Usage
- **Draw**: Click and hold the left mouse button, then drag.
- **Change Color**: Click a color button or use "More Colors".
- **Clear Canvas**: Click the "Clear" button.
